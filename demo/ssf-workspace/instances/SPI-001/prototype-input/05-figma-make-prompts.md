# 05 Figma Make Prompts

> 本文件给 Figma Make / Motiff / Uizard / 前端原型 AI 使用。请优先使用总 prompt，再按页面和流程补充。

## 1. 总 Prompt

```text
为“每日新闻 App”生成一个高保真可点击移动端原型。

产品目标：
帮助希望快速获取自己感兴趣内容的用户，在约 5 分钟内完成今日新闻判断，同时能通过兴趣标签、反馈、来源透明和隐私设置控制自己的信息流。

必须生成的页面：
- SCR-001 兴趣初始化页
- SCR-002 今日简报页
- SCR-003 标签管理页
- SCR-004 事件详情页
- SCR-005 保存与历史页
- SCR-006 设置与隐私页

必须打通的流程：
- PFLOW-001 新用户进入个性化简报：SCR-001 -> SCR-002 -> SCR-003 -> SCR-002
- PFLOW-002 从快读进入可信深读：SCR-002 -> SCR-004 -> SCR-005 -> SCR-004
- PFLOW-003 个性化反馈与隐私控制：SCR-002 -> SCR-006 -> SCR-003

设计风格：
移动端竖屏，高信息效率，浅色中性背景，克制可信，卡片半径不超过 8px，少量蓝色用于主动作，绿色用于成功状态，红色只用于危险操作。不要生成营销 hero、热榜、广告、社区评论、复杂装饰、渐变球或无关页面。

数据：
使用 prototype-input/04-sample-data.md 的 mock 数据。所有新闻、来源和时间都必须表现为示例数据，不要暗示是真实新闻。

标注：
frame 和 layer 名称保留 SCR/CMP/FEAT/BR/AC/PFLOW/PANN ID，方便交付和开发追踪。但这些 ID 不得出现在普通用户可见的界面文案中。
```

## 2. 页面 Prompt

### SCR-001 兴趣初始化页

```text
生成 SCR-001 Interest Onboarding。
用户可见标题为“选几个你关心的主题”，副文案为“之后可以随时调整”。
包含 CMP-101 标题、CMP-102 标签网格、CMP-103 搜索标签、CMP-104 已选标签、CMP-105 完成、CMP-106 跳过。
标签网格使用 12 个以内标签 chip：AI、财经、体育、本地、国际、健康、科技、教育、创业、汽车、气候、文化。
点击标签应体现选中态；完成进入 SCR-002；跳过进入默认 SCR-002。
不要生成登录、问卷进度条、营销说明页。
```

### SCR-002 今日简报页

```text
生成 SCR-002 Daily Brief。
顶部包含 CMP-201“今日简报”和 CMP-202“约 5 分钟 · 更新于 08:30”。
主体为 CMP-203 新闻卡/事件卡列表，使用 04-sample-data.md 的 NEWS-001 至 NEWS-006。
每张卡必须展示标题、摘要、来源、时间、标签、更多按钮 CMP-204 和“为什么推荐” CMP-207。
更多按钮打开 CMP-205，菜单包含不感兴趣、减少此类、隐藏来源、收藏、稍后读；动作后出现 CMP-206 toast。
底部 CMP-208 tab 包含简报、保存、设置，分别链接 SCR-002、SCR-005、SCR-006。
不要生成热榜、评论、广告、分享裂变、无限流。
```

### SCR-003 标签管理页

```text
生成 SCR-003 Interest Management。
顶部 CMP-301 显示“管理兴趣”。
包含 CMP-302 已关注标签可排序列表、CMP-303 排除标签、CMP-304 搜索新标签、CMP-305 推荐标签、CMP-306 保存调整。
关注标签和排除标签必须视觉区分。保存调整后返回 SCR-002。
展示默认、搜索空态和保存失败提示的轻量状态。
不要生成复杂知识图谱、多层级标签树或专业后台。
```

### SCR-004 事件详情页

```text
生成 SCR-004 Event Detail。
使用 EVT-001 mock 数据。
包含 CMP-401 事件标题、CMP-402 摘要卡、CMP-403 来源与原文入口、CMP-404 相关报道、CMP-405 收藏/稍后读、CMP-406 反馈/隐藏来源菜单。
来源信息必须靠近摘要，不要藏在页面底部。
点击稍后读出现 toast，并能从 SCR-005 回到该详情。
不要生成事实裁判、媒体评分、评论区。
```

### SCR-005 保存与历史页

```text
生成 SCR-005 Saved And History。
顶部 CMP-501 segmented control 包含收藏、稍后读、历史。
CMP-502 列表使用 04-sample-data.md 的保存与历史数据；点击列表项进入 SCR-004。
CMP-503 空态包含简短文案和去看简报入口。
CMP-504 使用移除图标，移除后列表即时变化。
保留底部 CMP-208 tab。
不要生成文件夹、笔记编辑器或协作知识库。
```

### SCR-006 设置与隐私页

```text
生成 SCR-006 Settings And Privacy。
包含 CMP-601 个性化说明卡、CMP-602 查看反馈记录、CMP-603 清除偏好/关闭个性化、CMP-604 提醒标签、CMP-605 每日最多提醒、CMP-606 免打扰、CMP-607 管理兴趣标签。
CMP-603 危险操作必须有二次确认弹窗。
通知设置组展示提醒标签、每日上限、免打扰；通知权限未开时展示权限提示。
CMP-607 链接 SCR-003。
不要生成账号中心、支付订阅、广告设置。
```

## 3. 流程 Prompt

```text
连接 PFLOW-001：SCR-001 中点击 CMP-102 选择标签，CMP-105 完成后进入 SCR-002；从 SCR-002 进入 SCR-003；在 SCR-003 点击 CMP-306 保存调整后返回 SCR-002。保留 CMP-106 跳过到默认简报的分支。
```

```text
连接 PFLOW-002：SCR-002 中点击 CMP-203 的 NEWS-001 进入 SCR-004；在 SCR-004 展示 CMP-403 来源与原文；点击 CMP-405 稍后读后可进入 SCR-005；在 SCR-005 点击 NEWS-001 返回 SCR-004。
```

```text
连接 PFLOW-003：SCR-002 中点击 CMP-204 打开 CMP-205，选择不感兴趣后显示 CMP-206；点击 CMP-207 显示推荐原因；通过 CMP-208 进入 SCR-006；在 SCR-006 点击 CMP-607 进入 SCR-003。
```

## 4. 修正 Prompt

当原型工具生成了不符合规格的内容时，使用以下修正指令：

```text
请修正当前原型，只保留 SCR-001 至 SCR-006 六个页面，不要新增热榜、评论、广告、社区、登录、支付、账号中心或后台页面。
保留 frame/layer/annotation 中的 SCR/CMP/FEAT/BR/AC/PFLOW/PANN ID，但不要把这些 ID 放进用户可见 UI 文案。
新闻数据必须来自 04-sample-data.md 的 mock 数据，每张新闻卡和事件详情都要展示来源、时间和标签。
```

```text
请强化来源透明：SCR-002 的每张 CMP-203 新闻卡必须显示来源和时间；SCR-004 的 CMP-403 必须紧随摘要区展示来源、时间和原文入口。不要生成无来源摘要。
```

```text
请降低视觉噪音：移除营销 hero、大面积渐变、装饰光斑、广告卡、热榜符号和社交评论。界面应像一个高效、可信的日常新闻工具。
```

## 5. Figma MCP / Handoff Prompt

```text
请为每个 frame 添加说明：
- frame 名称格式：SCR-xxx 英文页面名
- 关键 layer 名称格式：CMP-xxx 简短英文组件名
- 每个关键组件在 annotation 中记录关联 FEAT / BR / AC
- 用户界面文案中不要显示任何 SCR/CMP/FEAT/BR/AC/PFLOW/PANN ID
导出时保留页面顺序：SCR-001、SCR-002、SCR-003、SCR-004、SCR-005、SCR-006。
```
