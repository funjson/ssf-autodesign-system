## 1. 产品背景

- 背景概述：新闻来源、平台和内容形态持续增多，用户面临“信息足够多但判断成本过高”的问题。本产品用个性化简报、定制标签、事件聚合和来源透明，帮助用户在短时间内获得与自己相关的新闻判断。
- 关键用户问题：用户希望快速获取感兴趣内容，却常被泛化信息流、重复报道、标题党、通知噪音和来源不透明打断。
- 关键业务问题：产品必须在“高相关”“短时间”“可信任”“可控制”之间取得平衡，不能把个性化做成新的黑箱或新的信息爆炸。
- 相关洞察 ID：INS-001 / INS-002 / INS-003 / INS-004 / INS-005 / INS-006 / INS-007 / INS-008

## 2. 产品定位

| 项目 | 内容 |
|---|---|
| 产品一句话定位 | 面向碎片时间用户的个性化每日新闻快读 App，让用户用约 5 分钟读懂与自己相关的重要新闻。 |
| 目标用户 | 快速知情用户、兴趣驱动用户、专业追踪用户、轻量新闻用户。 |
| 使用场景 | 早晨简报、通勤浏览、午间行业追踪、突发新闻了解、睡前回顾和稍后深读。 |
| 核心价值 | 降低筛选成本、减少重复阅读、提供可控兴趣边界、保留来源透明和深读入口。 |
| 差异化方向 | 不是无限信息流，而是“标签可控 + 事件聚合 + 来源可追溯 + 克制通知”的快读体验。 |

| GOAL-002 | 让用户明确控制兴趣边界 | 用户可完成标签选择、编辑、排序、删除和稍后调整 | INS-002 / INS-006 |

### 4.2 范围外

| scope_id | 不覆盖内容 | 原因 |
|---|---|---|
| SCOPE-OUT-001 | 新闻采编后台和原创新闻生产 | 当前定位是聚合与效率工具，不是媒体生产系统 |
| SCOPE-OUT-002 | 社区评论、发帖、关注作者 | 当前核心任务是快速获取内容，不是社交讨论 |
| SCOPE-OUT-003 | 完整商业化、广告和订阅方案 | 用户未要求，且会干扰首版核心体验 |
| SCOPE-OUT-004 | 笔记、团队协作和知识库 | 会偏离新闻快读目标，阅读延展保持轻量 |
| SCOPE-OUT-005 | 事实核查或立场裁判 | 首版只做来源透明、多视角和摘要回溯，不替用户下判断 |
| SCOPE-OUT-006 | 企业级账号、权限和运营后台 | 当前是个人用户 App，账号同步仍待确认 |

## 5. 用户角色

| role_id | 角色名称 | 目标 | 主要操作 | 权限边界 |

| ROLE-004 | 轻量新闻用户 | 不想花太多时间但不想错过重要消息 | 查看简报、接收克制通知、关闭或调整提醒 | 只能控制个人通知和个性化设置 |
