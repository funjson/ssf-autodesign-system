## 4. 相关产品设计事实

### 4.1 功能任务

#### FEAT-001 个性化今日简报

- 目标：用户目标：在约 5 分钟内判断今天哪些新闻与自己相关、哪些值得深读。
业务目标：用简报形态替代无限滚动，强化短时高相关体验。
完成结果：用户看到按兴趣和重要度组织的新闻卡集合，并可进入详情、反馈或保存。
- 关联页面：SCR-002 / SCR-004
- 来源：product-spec/06-feature-task-spec.md

#### FEAT-003 内容反馈与偏好训练

- 目标：用户目标：通过明确反馈影响后续新闻相关性。
业务目标：建立用户可理解的个性化训练闭环。
完成结果：反馈被记录，用户看到反馈影响说明，并可在隐私页查看或清除。
- 关联页面：SCR-002 / SCR-004 / SCR-006
- 来源：product-spec/06-feature-task-spec.md

#### FEAT-004 同事件聚合与去重

- 目标：用户目标：避免同一事件反复阅读重复报道。
业务目标：用事件视图提高新闻信息密度和可理解性。
完成结果：同一事件下的多篇报道以事件卡和详情聚合呈现。
- 关联页面：SCR-002 / SCR-004
- 来源：product-spec/06-feature-task-spec.md

#### FEAT-005 摘要来源与多视角入口

- 目标：用户目标：快速核对摘要来自哪里，并进入多来源深读。
业务目标：减少 AI 摘要或推荐带来的信任风险。
完成结果：每条摘要或事件详情都展示来源、时间、原文入口和相关报道。
- 关联页面：SCR-004
- 来源：product-spec/06-feature-task-spec.md

#### FEAT-007 新闻卡反馈菜单

- 目标：用户目标：在阅读中快速执行反馈、隐藏来源、收藏或稍后读。
业务目标：把反馈动作放到新闻消费现场，减少设置页成本。
完成结果：新闻卡提供统一操作菜单，动作结果清晰可撤销或可继续。
- 关联页面：SCR-002 / SCR-004 / SCR-005 / SCR-006
- 来源：product-spec/06-feature-task-spec.md

#### FEAT-009 收藏、稍后读与历史

- 目标：用户目标：把值得深读的内容保存起来，并从历史继续阅读。
业务目标：支持从快读到深读，不把产品扩展为知识库。
完成结果：用户可查看收藏、稍后读和阅读历史。
- 关联页面：SCR-002 / SCR-004 / SCR-005
- 来源：product-spec/06-feature-task-spec.md

#### FEAT-010 个性化说明与偏好清除

- 目标：用户目标：理解为什么看到某条内容，并能清除或关闭个性化。
业务目标：降低黑箱推荐和隐私担忧。
完成结果：用户可查看个性化依据、反馈记录、清除偏好或关闭个性化。
- 关联页面：SCR-002 / SCR-006
- 来源：product-spec/06-feature-task-spec.md
