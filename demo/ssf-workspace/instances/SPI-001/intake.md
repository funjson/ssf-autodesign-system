# 00 Intake 信息收集

> Intake 是 `ssf-product-pm` 的公共入口能力模板，不作为产品版本文档，不参与 `v0.1 / v0.2` 产品基线编号。它用于在生成、重生成、续跑、跳阶段或变更前收集最小必要信息，并记录用户的关键选择。

## 1. Intake 元信息

| 字段 | 内容 |
|---|---|
| intake_id | INTAKE-001 |
| instance_id | SPI-001 |
| created_at | 2026-05-26 |
| user_request | 我现在要进行一个系统设计，目标是每日新闻的一个 app，目标用户是希望可以快速的获取自己感兴趣的内容信息的用户，也就是解决现在信息爆炸的问题，短时间之内获取内容是我们的目标，可以定制化标签是必须的能力，你来做下设计吧 |
| resolved_execution_mode | full-run |
| write_policy | 新建实例 |
