# 01 Design System Constraints

> 本文件约束原型的视觉、布局、组件和状态，不新增产品能力。

## 0. 元信息

| 字段 | 内容 |
|---|---|
| document_id | PROTO-DESIGN-SYSTEM-001 |
| instance_id | SPI-001 |
| source_documents | UI-SPEC-001 / PROTOTYPE-ANNOTATION-001 |
| review_gate | prototype-input-auto-review |

## 1. 设备与布局

| 项目 | 约束 |
|---|---|
| 端类型 | 移动端 App，高保真竖屏 |
| 推荐画板 | iPhone 15 / 393 x 852，可兼容 375 x 812 |
| 安全区 | 顶部状态栏和底部 Home Indicator 必须留出安全区 |
| 页面边距 | 主体左右 16px；卡片内边距 12-16px |
| 垂直节奏 | 区块间距 16-24px；列表项间距 8-12px |
| 固定区域 | 底部 tab 固定；关键底部操作按钮避开系统手势区 |
| 信息密度 | 首页展示 6-10 张新闻/事件卡；避免无尽流暗示 |

## 2. 视觉基调

| 维度 | 要求 |
|---|---|
| 关键词 | 快读、可信、低噪音、个性化、来源透明 |
| 背景 | 浅色中性背景，不使用大面积深色、复杂纹理、渐变球或装饰光斑 |
| 主色 | 低饱和蓝色用于主动作和当前 tab |
| 辅助色 | 绿色用于已保存/成功；琥珀色用于提醒；红色仅用于危险操作 |
| 卡片 | 半径不超过 8px；边框或轻阴影必须克制 |
| 分隔 | 用细线、留白和字号层级区分，不用厚重色块堆叠 |

## 3. 字体与层级

| 层级 | 建议 |
|---|---|
| 页面标题 | 24px 左右，字重 600-700 |
| 区块标题 | 16-18px，字重 600 |
| 新闻标题 | 16px，最多 2 行 |
| 摘要正文 | 14px，最多 2-3 行 |
| 来源/时间/标签 | 12-13px，低对比但可读 |
| 按钮文字 | 14-16px，避免过长 |

## 4. 组件约束

| component_family | 约束 | 关联组件 |
|---|---|---|
| 标签 chip | 必须有未选、已选、排除三种状态；长标签可换行或截断 | CMP-102 / CMP-104 / CMP-303 / CMP-305 |
| 新闻卡 | 稳定尺寸，包含标题、摘要、来源、时间、标签和操作 | CMP-203 |
| 菜单 | 反馈类和保存类动作视觉分组；更多按钮用图标 | CMP-204 / CMP-205 / CMP-406 |
| toast | 短暂、低干扰，文案不超过一行 | CMP-206 |
| 底部 tab | 仅包含简报、保存、设置；当前项高亮 | CMP-208 |
| segmented control | 三项等宽，状态清晰 | CMP-501 |
| 危险操作 | 与普通按钮区分，必须搭配确认弹窗 | CMP-603 |
| 通知设置 | selector、stepper/segmented、toggle/time-range 清晰分组 | CMP-604 / CMP-605 / CMP-606 |

## 5. 状态约束

| 状态 | 原型表现 |
|---|---|
| 默认 | 展示完整可读 mock 内容 |
| 加载 | 使用骨架屏，不用长篇解释 |
| 空态 | 给出简短说明和一个下一步入口 |
| 错误 | 显示失败原因和重试/返回入口 |
| 权限提示 | 仅 SCR-006 通知权限场景需要，表达克制 |
| 执行中 | 反馈、保存、清除偏好等动作可用按钮 loading 态 |

## 6. 禁止项

| prohibited_id | 禁止内容 |
|---|---|
| PDS-NO-001 | 不生成营销式 landing hero |
| PDS-NO-002 | 不生成热榜、广告、社区评论、分享裂变入口 |
| PDS-NO-003 | 不使用无来源新闻摘要 |
| PDS-NO-004 | 不把 SCR/CMP/FEAT/BR/AC ID 显示给普通用户 |
| PDS-NO-005 | 不新增超出 6 个页面的导航结构 |
| PDS-NO-006 | 不让紫色、米色、深蓝或单一色系占据整个界面 |
