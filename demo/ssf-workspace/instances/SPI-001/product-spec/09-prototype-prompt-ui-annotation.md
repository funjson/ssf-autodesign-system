## 1. 原型生成总约束

| 约束项 | 内容 |
|---|---|
| 原型类型 | 高保真可点击移动端原型 |
| 端类型 | 移动端 App |
| 视觉风格 | 克制、可信、信息效率优先；白底或浅色底，明确内容层级，避免花哨装饰 |
| 设计关键词 | 快读、个性化、来源透明、低噪音、清晰反馈 |
| 组件风格 | 稳定尺寸新闻卡、可选标签 chip、底部 tab、轻量菜单、清晰状态提示 |
| 文案风格 | 短句、明确、少承诺；摘要与推荐原因避免绝对化判断 |
| 禁止生成内容 | 社区评论、发帖、广告、营销 hero、无来源摘要、复杂背景、未定义页面 |
| 输出要求 | 6 个页面图、关键流程可点击、组件 ID 可标注 |

## 2. 页面级原型 Prompt

# SCR-001 兴趣初始化页 Prompt

```text
请生成页面：SCR-001 兴趣初始化页。
页面目标：让新用户快速选择或跳过兴趣标签。
端类型：移动端 App。
目标用户：ROLE-001 / ROLE-002 / ROLE-004。
关联功能：FEAT-002 / FEAT-006。

页面布局：
- 顶部说明区：CMP-101，标题“选几个你关心的主题”，一行说明“之后可以随时调整”。
- 推荐标签区：CMP-102，展示 12 个以内标签 chip，包含 AI、财经、体育、本地、国际等。
- 搜索与已选区：CMP-103 搜索标签，CMP-104 展示已选标签。
- 底部操作区：CMP-105 完成，CMP-106 跳过。

交互要求：
- 点击标签切换选中态。
- 点击完成进入 SCR-002。
- 点击跳过进入默认 SCR-002。

状态要求：
- 默认态：显示推荐标签、搜索、已选和底部操作。
- 加载态：标签区骨架。
- 空态：搜索无结果提示。
- 错误态：推荐标签加载失败时显示重试和跳过。

视觉要求：
- 轻量、低压迫，不像问卷。

不要生成：
- 强制登录、长问卷、营销说明页。
```

# SCR-002 今日简报页 Prompt

```text
请生成页面：SCR-002 今日简报页。
页面目标：展示约 5 分钟个性化新闻简报。
端类型：移动端 App。

关联功能：FEAT-001 / FEAT-003 / FEAT-004 / FEAT-007 / FEAT-010。

页面布局：
- 简报头部：CMP-201 标题“今日简报”，CMP-202 展示“约 5 分钟 · 更新于 xx:xx”。
- 新闻卡列表：CMP-203 展示 6-10 张新闻卡，卡内含标题、摘要、来源、时间、标签、事件标识。
- 卡片操作：CMP-204 更多按钮，CMP-205 反馈菜单，CMP-206 toast。
- 推荐原因：CMP-207 “为什么推荐”轻量入口。
- 底部导航：CMP-208 简报 / 保存 / 设置。

交互要求：
- 点击新闻卡进入 SCR-004。
- 点击更多展示反馈菜单。
- 点击保存或稍后读后出现 toast，可跳转 SCR-005。

状态要求：
- 默认态：简报列表完整。
- 加载态：卡片骨架。
- 空态：引导调整标签或查看通用简报。
- 错误态：重试入口。

视觉要求：
- 信息层级清楚，卡片尺寸稳定，避免无尽刷流感。

不要生成：
- 热榜、评论区、广告卡、社交分享流。
```

# SCR-004 事件详情页 Prompt

```text
请生成页面：SCR-004 事件详情页。
页面目标：展示摘要、来源、多视角、原文和操作入口。
端类型：移动端 App。
目标用户：ROLE-001 / ROLE-003 / ROLE-004。
关联功能：FEAT-004 / FEAT-005 / FEAT-007 / FEAT-009。

页面布局：
- 详情头部：CMP-401 事件标题，CMP-402 摘要卡。
- 来源与原文区：CMP-403 显示来源、时间、原文入口。
- 相关报道区：CMP-404 多来源报道列表。
- 操作区：CMP-405 收藏/稍后读，CMP-406 反馈/隐藏来源菜单。

交互要求：
- 点击原文入口打开外部原文或待定阅读容器。
- 点击相关报道查看报道。

- 内容失效态：提示不可访问，可返回或移除保存。

视觉要求：
- 来源信息要接近摘要，不能藏在底部。

不要生成：

```
